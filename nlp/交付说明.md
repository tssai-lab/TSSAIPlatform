# TSS AI Platform NLP CPU/单卡 GPU 验收包

版本日期：2026-08-29

本包以 MiniRBT-H288 和 Amazon Science MASSIVE v1.1 中文数据验证平台的 NLP 基础功能闭环：

`训练方案导入 → 模型/数据集/代码上传 → 风险扫描与审批 → CPU 或单卡 GPU 训练 → 日志与指标 → 结果模型 → 推理`

## 主要文件

- `minirbt_text_classification-v1.yaml`：CPU 训练方案；
- `minirbt_text_classification_gpu-v1.yaml`：单卡 NVIDIA GPU 训练方案；
- `minirbt-h288-base.zip`：MiniRBT-H288 基础模型；
- `massive-zhcn-intent-dataset.zip`：MASSIVE `zh-CN` 六类意图固定子集，共 240 条；
- `minirbt-training-code.zip`：训练代码，入口 `train.py`；
- `minirbt-inference-script.zip`：推理代码，入口 `infer.py`；
- `acceptance-manifest.json`、`SHA256SUMS.txt`：文件来源与完整性校验；
- `README.md`：数据契约、验证规则和验收边界。

## 使用边界

本包已验证内网单卡 GPU 训练和 CPU 推理闭环，不代表生产精度、吞吐量、并发、多卡或大数据训练能力。GPU 验收默认训练 1 轮，不设最低准确率门槛；CPU 训练方案已提供，但尚未执行目标平台真实训练。

2026-08-29 的稳定性验证连续执行 3 次训练，均使用同一张 RTX 4080、同一固定摘要镜像和相同随机种子，三次均成功并分别生成独立模型版本；随后使用第 3 个模型完成 20 条文本推理。
