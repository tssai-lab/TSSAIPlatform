# TSS AI Platform NLP CPU 验收包

版本日期：2026-08-27

本包用于在无 GPU 环境中，以 MiniRBT-H288 和 Amazon Science MASSIVE v1.1 中文数据验证平台的 NLP 基础功能闭环：

`训练方案导入 → 模型/数据集/代码上传 → 代码审批 → CPU 训练 → 日志与指标 → 结果模型 → 推理`

## 主要文件

- `minirbt_text_classification-v1.yaml`：CPU 训练方案；
- `minirbt-h288-base.zip`：MiniRBT-H288 基础模型；
- `massive-zhcn-intent-dataset.zip`：MASSIVE `zh-CN` 六类意图固定子集，共 240 条；
- `minirbt-training-code.zip`：训练代码，入口 `train.py`；
- `minirbt-inference-script.zip`：推理代码，入口 `infer.py`；
- `acceptance-manifest.json`、`SHA256SUMS.txt`：文件来源与完整性校验；
- `README.md`：数据契约、验证规则和验收边界。

## 使用边界

本包验证的是平台的 CPU 训练和推理流程，不代表生产精度、吞吐量、并发、GPU 或大数据训练能力。默认只训练 2 轮，不设最低准确率门槛。
