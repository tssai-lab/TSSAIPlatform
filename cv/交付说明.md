# TSS AI Platform CV CPU 验收包

版本日期：2026-08-27

本包用于在无 GPU 环境中，以小型 YOLO11n 模型和官方 COCO128 数据验证平台的 CV 基础功能闭环：

`训练方案导入 → 模型/数据集/代码上传 → 代码审批 → CPU 训练 → 日志与指标 → 结果模型 → 推理`

## 主要文件

- `yolov11n_object_detection_cpu-v1.yaml`：CPU 训练方案；
- `yolo11n-base-model.zip`：YOLO11n 基础模型；
- `yolo11n-coco128-dataset.zip`：从官方 COCO128 确定性整理的 128 张图片数据集；
- `yolo11n-training-code.zip`：训练代码，入口 `train.py`；
- `yolo11n-inference-script.zip`：推理代码，入口 `infer.py`；
- `acceptance-manifest.json`、`SHA256SUMS.txt`：文件来源与完整性校验；
- `README.md`、`COCO128_SOURCE_AND_LICENSE.md`：技术细节、数据来源及修改说明。

## 使用边界

本包验证的是平台的 CPU 训练和推理流程，不代表生产精度、吞吐量、并发、GPU 或分布式训练能力。默认只训练 2 轮，不设最低 mAP 门槛。
