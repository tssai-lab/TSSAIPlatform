# CV CPU 验收操作步骤

## 一、准备条件

1. 平台前后端、数据库、对象存储和 CPU 计算节点正常；
2. CPU 节点带有标签 `tss.ai/node-pool=cpu`；
3. 节点已有平台规定的 CV CPU 训练镜像；
4. 超级管理员可以导入训练方案并审批训练代码；
5. 单个任务建议至少分配 4 核 CPU、8 GiB 内存和 12 GiB 临时磁盘上限。

## 二、操作步骤

1. 导入 `yolov11n_object_detection_cpu-v1.yaml`；
2. 上传 `yolo11n-base-model.zip`，资产大类选择 `CV`；
3. 上传 `yolo11n-coco128-dataset.zip`，资产大类选择 `CV`。若页面仍显示旧的细分类，任务类型选择“目标检测（OBJECT_DETECTION）”，标注格式选择“YOLO”；
4. 上传 `yolo11n-training-code.zip`，入口文件填写 `train.py`，由超级管理员审批；
5. 新建训练任务，选择“YOLO11n 小型目标检测验收（CPU）”，再选择上述模型、数据集和代码；
6. 保持默认参数：`epochs=2`、`batch=2`、`imgsz=160`、`learningRate=0.001`；
7. 启动训练，确认任务成功，日志与指标可查看，并能下载 `best.pt`、`last.pt` 和 `metrics.json`；
8. 上传 `yolo11n-inference-script.zip`，入口文件填写 `infer.py`，选择训练生成的 `best.pt` 发起推理；
9. 确认推理完成，检测结果可以查看或下载。

## 三、通过标准

- 资产和训练方案能被平台接受；
- 训练任务在 CPU 节点实际运行并成功结束；
- 页面展示真实进度、日志和指标；
- 结果模型可以下载并用于一次推理；
- Job/Pod 清理后，已归档的日志、指标和结果仍可查看；
- 失败时页面显示真实原因并保留排查信息。
