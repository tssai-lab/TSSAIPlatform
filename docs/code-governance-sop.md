## G1 上下文与默认决策

### A：可确认事实

- `deploy/main/mlflow-lite/app.py:get_metric_history` 正常无记录返回 `metrics: []`，异常返回 HTTP 500。
- 前端指标支持标准名称及别名；返回类型允许省略 `metrics`。训练详情与结果对比共用该服务。
- 本人代码列表优先 V2；旧接口不能完整返回待审、拒绝等版本，因此已有本地上传登记补充。
- `apiCompatibility.mjs` 仅允许无业务错误码的 404/405/501 判为旧端点不支持。
- 原有 `npm test`、`max setup`、`npm run tsc`、生产构建作为本地回归入口。

### B：有依据的低风险默认规则

- 指标正常为空才尝试别名；网络、鉴权、服务错误向上报告，不伪装为空。保留无 `metrics` 的正常对象兼容，不接受错误对象或错误字段类型。
- 同一 Run 刷新失败保留旧数据及成功时间，提示“未更新”；更换 Run 或卸载后旧响应不得覆盖新页面。
- 代码版本部分读取失败时保留成功部分并持续提示不完整；全部失败则明确报错。本地登记不充当远端查询成功证据。
- 仅 V2 资产入口不支持时读取旧接口；已进入 V2 后，单个资产失败不触发整表降级。可选名称/风险信息补全沿用原行为。

### C：本次不擅自决定的业务事项

- 不更改权限、审核规则、资产归属、删除、任务提交、重试、数据库和对外 API。
- 不移除 legacy API 或 Fabric8/kubectl，不把兼容实现当成冗余代码删除。
- 远端发布前另做版本对齐与只读页面验收；本地测试不能代替实际训练或交付验收。
