# Demo 需求文档

适用分支：`demo`。版本：1.0。更新日期：2026-10-23。

## 1. 目标与范围

用于演示完整操作链路：账号登录 → 平台选择 → 训练平台或数据标注平台。演示重点是用户上传自己的图像、工业时序数据，手工标注并保存。原自动化标注开发代码独立保留，本 Demo 不覆盖原开发目录。

当前名称为“数据标注平台”，不称为“自动化标注平台”。产品以可演示、操作清晰为目标，不按完整商业标注系统设计。

## 2. 用户与权限

| 角色 | 账号初始化后的用户名 | 用途 |
| --- | --- | --- |
| 超级管理员 | `demo_root` | 账号与角色管理、平台管理演示 |
| 管理员 | `demo_admin` | 训练平台中管理员可见的功能演示 |
| 普通用户 | `demo_user` | 上传自己的数据、标注、保存和导出 |

上述账号不是 Git 中预置的数据库记录，需执行初始化工具才创建，密码为各自随机生成的 16 位密码。手工注册账号默认是普通用户。

人工标注项目按登录用户隔离，管理员也不自动获得其他用户的标注项目访问权；三个演示账号不会共用一套标注项目。

## 3. 功能需求与验收条件

| 编号 | 功能 | 当前实现及验收条件 |
| --- | --- | --- |
| D01 | 登录、注册 | 支持用户名密码登录及用户名注册；默认部署关闭短信服务，手机号注册/登录不作为必需演示项 |
| D02 | 平台选择 | 登录后只显示“训练平台”和“数据标注平台”，没有 AI 安全平台入口 |
| D03 | 训练平台 | 保留数据集、模型、训练、推理及相关管理界面；真实任务执行依赖外部计算服务，界面可访问不等于任务可执行 |
| D04 | 项目创建 | 输入项目名称，从本机选择 ZIP、TAR、TAR.GZ 或 TGZ；每次上传新建一个项目 |
| D05 | 上传与处理 | 分块上传，显示进度，允许暂停及选择原文件继续；后台整理文件并显示可标注状态或错误原因 |
| D06 | 项目保存 | 分别保存项目名称、原始压缩包文件名、数据文件及标注；刷新或重新登录后可继续处理自己的项目 |
| D07 | 图像标注 | 支持整图分类与矩形框；选中已有框后修改标签并应用，不能因此新增重复框 |
| D08 | 时序标注 | 支持数值 CSV、TEP DAT，切换通道，拖选或输入区间，设置状态、故障、涉及通道与备注 |
| D09 | 保存与导出 | 点击保存后写入标注后端；导出标注 JSON。导出不包含原始文件，也不是完整项目迁移包 |
| D10 | 视觉与文案 | 标注平台显著展示东南大学校徽和名称；平台选择页保留 TSS 品牌；按钮清晰，减少重复介绍文字 |
| D11 | 隔离与异常 | 未登录不能读取项目；不能读取其他用户的项目；有版本冲突时拒绝静默覆盖 |

## 4. 数据与标签

图像支持 JPG、JPEG、PNG、WebP。当前界面提供产品类别、正常/异常/待确认、缺陷类别及备注；缺陷类别包括缺损、表面斑点、异物/附着物、划痕等。正常图片可只添加整图分类，异常区域分别画框。产品与缺陷菜单是演示版固定配置，不是可由用户任意编辑的标签体系。

时序支持正常、异常、待确认，故障编号及涉及通道。TEP 为 52 通道数据，解析器处理其特定布局。故障标签应结合数据说明人工选择，不根据文件名或曲线自动作出诊断。

VisA 与 TEP 是已有演示资料的来源。数据集的既有标签、掩码和故障编号不等于本平台已自动生成的标注。ZIP 中的说明文件及 VisA 掩码会按规则跳过，平台显示有效数据文件数量。

## 5. 约束

- 正常入口为“项目管理”，用户上传本机压缩包，不选择服务器目录。
- 单次上传默认最大 10 GB、解压累计最大 20 GB，受可用磁盘限制；每块 8 MB。
- 最多三层嵌套归档；每个项目最多 20000 个有效数据文件。
- 单个时序文件最多 64 MB、50000 个采样点；不支持超长序列按窗口查询。
- 项目列表为最近 100 个项目，项目内列表每页 50 个文件。
- 保存按钮保存当前已加载页的标注；切换页面前应先保存，不能把“已绘制”视为“已持久化”。
- 标注服务为单实例 SQLite 服务，并非分布式存储系统。
- 旧 `/manual-label` 本机浏览器工作区仍保留，其容量限制和保存位置不同，不作为新用户主要演示入口。

## 6. 当前不做

模型自动标注、Label Studio 集成、用户自定义标签体系、多人同时协作同一项目、项目共享与转移、项目重命名或删除界面、自动把标注结果发布为训练数据集、真实训练基础设施的自动搭建。

服务器管理员可以维护数据，但 UI 没有删除项目按钮。数据库备份和文件备份需一起规划；不能仅复制标注 JSON 就宣称完整项目已备份。

## 7. 推荐演示顺序

1. 登录 `demo_user`，展示两个平台入口。
2. 进入训练平台，展示数据与模型管理；没有计算服务时不演示实际训练完成。
3. 返回平台选择，进入数据标注平台，新建一个图像项目并上传小型 ZIP。
4. 画框、选择标签、应用到所选框、保存，刷新后检查标签仍在。
5. 新建一个时序项目，上传 CSV 或 DAT 压缩包，选择通道和区间，保存并导出。
6. 退出，换另一账号登录，验证项目隔离。

详细部署和逐项记录见[账号初始化指南](account-initialization.md)及[部署验收清单](deployment-acceptance.md)。
